**PARKED — Android native shell (out of scope for MVP).** The Capacitor-based Android app in this directory was moved to `archive/android/` and is explicitly unsupported for the BibleDesk MVP: no APK/AAB is built, signed, or shipped, and the web PWA is the mobile story. Reviving it later would require re-verifying the prerequisites listed in the distribution deep-dive doc (research/deep/18-distribution-deep-dive.md §6) — a working Capacitor build pipeline, signing keys and store release process, native-bridge code for any device APIs, and product sign-off that the native shell adds value over the PWA — then moving this directory back to `apps/android/` and updating the parked packaging scripts.
